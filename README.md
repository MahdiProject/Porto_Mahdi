# Portfolio Muhammad Mahdi

Website portfolio pribadi dibuat dengan **Next.js** + **Tailwind CSS**.

## Cara Menjalankan di VS Code

1. Extract file archive ini
2. Buka folder `portfolio-mahdi` di VS Code
3. Buka terminal di VS Code (`Ctrl + \``)
4. Install dependencies:
   ```bash
   npm install
   ```
5. Jalankan development server:
   ```bash
   npm run dev
   ```
6. Buka browser di [http://localhost:3000](http://localhost:3000)

## Deploy ke Vercel (Gratis)

1. Push project ke GitHub
2. Buka [vercel.com](https://vercel.com) → Import project
3. Pilih repository → Deploy

## Struktur

- `src/app/page.tsx` → Halaman utama (semua section ada di sini)
- `src/app/layout.tsx` → Layout & metadata
- `src/app/globals.css` → Styling global + Tailwind
